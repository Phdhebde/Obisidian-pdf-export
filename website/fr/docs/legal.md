## Confidentialité

### Le plugin

Report Exporter ne collecte aucune donnée. Il fonctionne entièrement hors ligne dans Obsidian : aucune requête réseau, aucune télémétrie, aucun compte. Vos notes, modèles et fichiers exportés restent sur votre ordinateur.

### Ce site

- **Aucun cookie, aucune mesure d'audience, aucune publicité.** L'éditeur ne collecte aucune donnée personnelle par ce site.
- **Préférences dans votre navigateur.** Le site retient quelques préférences d'affichage (par exemple le mode clair ou sombre) dans le stockage local de votre navigateur. Elles ne quittent pas votre appareil et servent uniquement à afficher le site.
- **Polices.** Les polices (Inter et JetBrains Mono) sont servies par le site lui-même : aucune requête n'est envoyée à Google Fonts ni à un autre service de polices.
- **Hébergement.** Comme tout hébergeur, GitHub reçoit les données techniques envoyées par votre navigateur au chargement d'une page, comme votre adresse IP, et peut les conserver dans ses journaux, par exemple pour la sécurité. Voir la [déclaration de confidentialité de GitHub](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement).
- **Liens vers GitHub.** Ouvrir une issue, une discussion ou une pull request se fait sur GitHub, selon les [conditions d'utilisation](https://docs.github.com/fr/site-policy/github-terms/github-terms-of-service) et la déclaration de confidentialité de GitHub.

### Vos droits

L'éditeur ne détenant aucune donnée personnelle sur les visiteurs, il n'y a rien à consulter, rectifier ou supprimer de son côté. Pour les données détenues par GitHub, adressez-vous à GitHub. Vous pouvez introduire une réclamation auprès de la [CNIL](https://www.cnil.fr).
